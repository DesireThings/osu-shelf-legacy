This is a minor release. Its one change is the licence: osu-shelf is now free software under the GNU General Public License v3.0 or later (GPL-3.0-or-later). The app itself works exactly as it did in 0.5.0. It's in early access: versions stay at 0.x until it's stable enough for 1.0.0.

osu-shelf is an unofficial community tool, not made, endorsed or supported by ppy (osu!) or osu!Collector.

## What's new since 0.5.0

- **New licence: GPL-3.0-or-later.** osu-shelf stays free to use, share and change. If you share a copy or a changed version, you have to make its source code available under the same licence. This applies from 0.6.0; see **Licences** below for what stays under other terms.
- **The licence text is in the release.** `LICENSE` and `NOTICE` are new in the repository, and `THIRD-PARTY-LICENSES.txt` and `THIRD-PARTY-LICENSES-desktop.txt` now start with osu-shelf's own notice and licence.
- **About screen.** **Settings → About** now shows the new licence and copyright, and its button is now **Show licences**, because the list covers osu-shelf's own licence as well as everything built into the app.

There are no new features or fixes in this release.

## Known limits

- **Browse can only filter what it has loaded.** osu!Collector's listing has no tags and no size, star or mode filters, so those apply to the rows already fetched, and **Load more** fetches up to three more pages to find matches. Star ranges are approximate, and sizes count difficulties, not map sets.
- **Listing counts can be out of date.** A collection's difficulty count in the listing can differ from what you get when you add it (for example 354 against 422).
- **Changing the sort needs Search pressed** before it takes effect.
- **The Windows and macOS builds haven't been run on a real Windows PC or Mac yet.** That covers the installers, the Windows one-line installer, and finding osu!lazer and Torii folders on those systems. They're built and checked automatically; please [open an issue](https://github.com/DesireThings/osu-shelf/issues/new) if something doesn't work.
- **macOS:** Apple Silicon only; there are no Intel Mac builds.
- **The desktop app doesn't update itself.** To update, download and install the new version over the old one. The terminal app does update itself.
- **Find in the desktop app** lists map sets only: there's no per-difficulty view yet, and searches through osu! don't show download sizes.
- **Update in the desktop app** lists missing map sets by number (each links to its osu! page), not by title, and can't yet mark a set as already installed or check failed maps again.

## Checking the files

`SHA256SUMS` lists the SHA-256 of every file in this release. On Linux or macOS, in the folder with your downloads: `sha256sum -c SHA256SUMS --ignore-missing` (on macOS, `shasum -a 256 -c SHA256SUMS --ignore-missing`).
